# Contributing

Thanks for helping out.

1. Open an issue first for anything bigger than a small fix, so we can agree on the approach.
2. Fork the repo and make a branch off `main`.
3. Keep changes focused, and add or update tests and docs where it makes sense.
4. Open a pull request describing what changed and why.

Security problems: don't open a public issue. See [SECURITY.md](SECURITY.md).

By contributing you agree to follow our [Code of Conduct](CODE_OF_CONDUCT.md) and to license your work under the repo's license.
